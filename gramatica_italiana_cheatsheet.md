## 1. Alfabeto e Pronúncia

| Letra | Pronúncia aproximada | Exemplo |
|-------|----------------------|---------|
| A     | á                    | *casa*  |
| E     | é / ê                | *bene* / *perché* |
| I     | i                    | *vino*  |
| O     | ó / ô                | *ora* / *sono* |
| U     | u                    | *luna*  |
| C + e/i | tch                | *ciao* (tchau) |
| C + a/o/u | k                 | *casa*  |
| G + e/i | dj                 | *gelato* |
| G + a/o/u | g (duro)          | *gatto* |
| GLI   | lh                   | *famiglia* |
| GN    | nh                   | *gnocchi* |
| SC + e/i | sh                 | *pesce* |
| Z     | ts / dz              | *pizza* / *zero* |

**Acentos:**  
- Átono (grave): à, è, ì, ò, ù  
- Tônico (agudo): é, ó (mais raros)

## 2. Artigos

### Artigos Definidos (o, a, os, as)

| Gênero / Número | Singular | Plural |
|-----------------|----------|--------|
| Masculino       | **il** (diante de consoante) / **lo** (s+consoante, z, gn, ps, x, y) / **l'** (vogal) | **i** / **gli** |
| Feminino        | **la** / **l'** (vogal) | **le** |

**Exemplos:**  
- il libro → i libri  
- lo studente → gli studenti  
- l'amico → gli amici  
- la casa → le case  
- l'amica → le amiche  

### Artigos Indefinidos (um, uma)

| Gênero     | Forma |
|------------|-------|
| Masculino  | **un** / **uno** (s+consoante, z, etc.) |
| Feminino   | **una** / **un'** (vogal) |

**Exemplos:** un libro, uno studente, una casa, un'amica

### Artigos Partitivos (alguns, um pouco de)
- **del, dello, della, dell', dei, degli, delle**  
  Ex: *Voglio del pane* (Quero um pouco de pão)

## 3. Substantivos (Gênero e Número)

### Formação do Plural

| Singular | Plural | Regra |
|----------|--------|-------|
| -o (masc.) | -i | libro → libri |
| -a (fem.)  | -e | casa → case |
| -e (masc./fem.) | -i | studente → studenti / chiave → chiavi |
| -ista      | -isti / -iste | turista → turisti/turiste |
| -à, -ù, -ì | invariável | città → città |

**Atenção:**  
- Alguns masculinos em -a: *il problema* → *i problemi*  
- Substantivos em -co/-go: *amico* → *amici* / *banco* → *banchi*

---

## 4. Adjetivos

### Concordância
Os adjetivos concordam em gênero e número com o substantivo.

| Tipo | Singular Masc. | Singular Fem. | Plural Masc. | Plural Fem. |
|------|----------------|---------------|--------------|-------------|
| -o   | bello          | bella         | belli        | belle       |
| -e   | grande         | grande        | grandi       | grandi      |

**Posição:**  
- Geralmente **depois** do substantivo: *una casa bella*  
- Alguns mudam de significado se colocados antes: *un grande uomo* (um grande homem) vs *un uomo grande* (um homem alto)

### Comparativos e Superlativos
- Comparativo de igualdade: **tanto... quanto** / **così... come**  
- Comparativo de superioridade: **più... di/che**  
- Comparativo de inferioridade: **meno... di/che**  
- Superlativo relativo: **il più / la più... di**  
- Superlativo absoluto: **-issimo** (*bellissimo*) ou **molto** + adjetivo

## 6. Verbos

### Conjugações Regulares (Presente do Indicativo)

| Pessoa | -ARE (parlare) | -ERE (credere) | -IRE (dormire) | -IRE (capire)* |
|--------|----------------|----------------|----------------|----------------|
| io     | parlo          | credo          | dormo          | capisco        |
| tu     | parli          | credi          | dormi          | capisci        |
| lui/lei| parla          | crede          | dorme          | capisce        |
| noi    | parliamo       | crediamo       | dormiamo       | capiamo        |
| voi    | parlate        | credete        | dormite        | capite         |
| loro   | parlano        | credono        | dormono        | capiscono      |

\* Verbos em -ire do tipo *capire, finire, preferire* usam **-isc-**

### Verbos Auxiliares (essenciais)

**ESSERE (ser/estar)**  
io sono · tu sei · lui/lei è · noi siamo · voi siete · loro sono

**AVERE (ter)**  
io ho · tu hai · lui/lei ha · noi abbiamo · voi avete · loro hanno

### Passato Prossimo (Pretérito Perfeito)
Auxiliar (essere ou avere) + particípio passado

| Tipo de verbo | Particípio |
|---------------|------------|
| -ARE          | -ato (*parlato*) |
| -ERE          | -uto (*creduto*) |
| -IRE          | -ito (*dormito*) |

**Regra do auxiliar:**  
- A maioria dos verbos → **avere**  
- Verbos de movimento, mudança de estado e reflexivos → **essere** (e o particípio concorda com o sujeito)

### Outros Tempos Importantes

**Imperfetto** (hábito no passado)  
-ARE: parlavo, parlavi, parlava, parlavamo, parlavate, parlavano  
-ERE: credevo, credevi...  
-IRE: dormivo, dormivi...

**Futuro Semplice**  
-ARE/-ERE: parlerò, parlerai, parlerà, parleremo, parlerete, parleranno  
-IRE: dormirò, dormirai...

**Condizionale Presente**  
parlerei, parleresti, parlerebbe, parleremmo, parlereste, parlerebbero

### Verbos Irregulares Mais Comuns

| Infinitivo | Presente (io / tu / lui) | Particípio |
|------------|---------------------------|------------|
| andare     | vado / vai / va           | andato     |
| venire     | vengo / vieni / viene     | venuto     |
| fare       | faccio / fai / fa         | fatto      |
| dire       | dico / dici / dice        | detto      |
| potere     | posso / puoi / può        | potuto     |
| volere     | voglio / vuoi / vuole     | voluto     |
| dovere     | devo / devi / deve        | dovuto     |
| sapere     | so / sai / sa             | saputo     |
| dare       | do / dai / dà             | dato       |
| stare      | sto / stai / sta          | stato      |
| bere       | bevo / bevi / beve        | bevuto     |
| uscire     | esco / esci / esce        | uscito     |

## 8. Estrutura da Frase

**Ordem básica:** Sujeito + Verbo + Objeto  
*Io mangio la pizza.*

**Negação:** **non** antes do verbo  
*Non mangio la pizza.*

**Perguntas:**  
- Entonação ascendente ou  
- **Che / Chi / Dove / Quando / Perché / Come / Quanto**  
  *Dove abiti?* (Onde você mora?)

**Há / Existe:**  
- **C’è** (singular) / **Ci sono** (plural)  
  *C’è un problema.* · *Ci sono due libri.*

## 10. Dicas Rápidas

1. O **r** italiano é vibrante (como o “rr” espanhol).  
2. A sílaba tônica quase sempre é a **penúltima**.  
3. Use **Lei** (com L maiúsculo) para formalidade.  
4. Em italiano, o artigo é usado com mais frequência do que em português.  
5. Verbos reflexivos são muito comuns: *svegliarsi, alzarsi, lavarsi...*
