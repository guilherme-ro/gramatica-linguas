# 🇪🇸 Cheat Sheet de Gramática do Espanhol

> Resumo rápido e prático das regras essenciais.

---

## 1. Artigos

### Definidos
| Gênero / Número | Singular | Plural |
|-----------------|----------|--------|
| Masculino       | **el**   | **los** |
| Feminino        | **la**   | **las** |
| Neutro          | **lo**   | —      |

### Indefinidos
| Gênero / Número | Singular | Plural |
|-----------------|----------|--------|
| Masculino       | **un**   | **unos** |
| Feminino        | **una**  | **unas** |

**Contracciones:**
- `a + el` → **al**
- `de + el` → **del**

---

## 2. Substantivos (Sustantivos)

### Gênero
- Terminam em **-o** → geralmente masculino (`el libro`)
- Terminam em **-a** → geralmente feminino (`la casa`)
- Exceções comuns:
  - Masculinos em **-a**: *el día, el problema, el mapa, el tema, el clima*
  - Femininos em **-o**: *la mano, la radio, la foto, la moto*

### Número (Plural)
| Terminação          | Regra                          | Exemplo              |
|---------------------|--------------------------------|----------------------|
| Vogal               | + **s**                        | *casa → casas*       |
| Consoante           | + **es**                       | *árbol → árboles*    |
| **-z**              | **z → c** + **es**             | *luz → luces*        |
| **-ión / -ción**    | + **es** (sem acento)          | *nación → naciones*  |

---

## 3. Adjetivos

### Concordância
Concordam em **gênero** e **número** com o substantivo:

| Forma          | Exemplo                  |
|----------------|--------------------------|
| Masculino sing.| *un libro interesante*   |
| Feminino sing. | *una casa interesante*   |
| Masculino pl.  | *unos libros interesantes*|
| Feminino pl.   | *unas casas interesantes*|

### Posição
- **Antes** do substantivo → valor subjetivo/afetivo  
  *un buen amigo* / *una gran casa*
- **Depois** do substantivo → valor objetivo/descritivo  
  *un amigo bueno* / *una casa grande*

### Adjetivos irregulares comuns
| Masculino | Feminino | Significado     |
|-----------|----------|-----------------|
| bueno     | buena    | bom             |
| malo      | mala     | mau             |
| grande    | grande   | grande          |
| bueno → **buen** (antes de masc. sing.) | | |
| malo → **mal** (antes de masc. sing.)   | | |
| grande → **gran** (antes de singular)   | | |

---

## 4. Pronomes

### Pessoais (sujeito)
| Pessoa | Singular | Plural     |
|--------|----------|------------|
| 1ª     | **yo**   | **nosotros/as** |
| 2ª     | **tú** / **usted** | **vosotros/as** / **ustedes** |
| 3ª     | **él / ella** | **ellos / ellas** |

> Em espanhol o sujeito costuma ser omitido porque o verbo já indica a pessoa.

### Pronomes objeto
| Tipo          | Singular                  | Plural                    |
|---------------|---------------------------|---------------------------|
| Direto (OD)   | **me, te, lo/la**         | **nos, os, los/las**      |
| Indireto (OI) | **me, te, le**            | **nos, os, les**          |

**Ordem quando juntos:** OI + OD  
- *Me lo dio* (Ele me deu isso)  
- *Se lo di* (Eu o dei a ele/ela) → **le/les** vira **se** antes de **lo/la/los/las**

### Possessivos
| Pessoa     | Átonos (antes)     | Tônicos (depois/isolados)      |
|------------|--------------------|--------------------------------|
| 1ª sing.   | **mi(s)**          | **mío/a(s)**                   |
| 2ª sing.   | **tu(s)**          | **tuyo/a(s)**                  |
| 3ª         | **su(s)**          | **suyo/a(s)**                  |
| 1ª pl.     | **nuestro/a(s)**   | **nuestro/a(s)**               |
| 2ª pl.     | **vuestro/a(s)**   | **vuestro/a(s)**               |

### Demonstrativos
| Distância     | Masculino     | Feminino      | Neutro   |
|---------------|---------------|---------------|----------|
| Perto         | **este/estos**| **esta/estas**| **esto** |
| Médio         | **ese/esos**  | **esa/esas**  | **eso**  |
| Longe         | **aquel/aquellos** | **aquella/aquellas** | **aquello** |

## 5. Verbos – Conjugações Essenciais

### Presente do Indicativo (regulares)
| Pessoa     | -AR (hablar) | -ER (comer) | -IR (vivir) |
|------------|--------------|-------------|-------------|
| yo         | habl**o**    | com**o**    | viv**o**    |
| tú         | habl**as**   | com**es**   | viv**es**   |
| él/ella/ud.| habl**a**    | com**e**    | viv**e**    |
| nosotros   | habl**amos** | com**emos** | viv**imos** |
| vosotros   | habl**áis**  | com**éis**  | viv**ís**   |
| ellos/uds. | habl**an**   | com**en**   | viv**en**   |

### Pretérito Perfeito Simples (Pretérito Indefinido)
| Pessoa     | -AR          | -ER / -IR        |
|------------|--------------|------------------|
| yo         | habl**é**    | com**í** / viv**í** |
| tú         | habl**aste** | com**iste** / viv**iste** |
| él/ella/ud.| habl**ó**    | com**ió** / viv**ió** |
| nosotros   | habl**amos** | com**imos** / viv**imos** |
| vosotros   | habl**asteis**| com**isteis** / viv**isteis** |
| ellos/uds. | habl**aron** | com**ieron** / viv**ieron** |

### Imperfeito
| Pessoa     | -AR          | -ER / -IR        |
|------------|--------------|------------------|
| yo         | habl**aba**  | com**ía** / viv**ía** |
| tú         | habl**abas** | com**ías** / viv**ías** |
| él/ella/ud.| habl**aba**  | com**ía** / viv**ía** |
| nosotros   | habl**ábamos**| com**íamos** / viv**íamos** |
| vosotros   | habl**abais**| com**íais** / viv**íais** |
| ellos/uds. | habl**aban** | com**ían** / viv**ían** |

### Futuro Simples
Raiz do infinitivo + terminações:
**é, ás, á, emos, éis, án**

- *hablaré, hablarás, hablará, hablaremos, hablaréis, hablarán*

### Condicional
Raiz do infinitivo + terminações:
**ía, ías, ía, íamos, íais, ían**

- *hablaría, hablarías, hablaría...*

### Presente do Subjuntivo (regulares)
| Pessoa     | -AR          | -ER / -IR        |
|------------|--------------|------------------|
| yo         | habl**e**    | com**a** / viv**a** |
| tú         | habl**es**   | com**as** / viv**as** |
| él/ella/ud.| habl**e**    | com**a** / viv**a** |
| nosotros   | habl**emos** | com**amos** / viv**amos** |
| vosotros   | habl**éis**  | com**áis** / viv**áis** |
| ellos/uds. | habl**en**   | com**an** / viv**an** |

## 6. Verbos Irregulares Mais Importantes

### Ser × Estar
| Uso do **SER**                  | Uso do **ESTAR**                |
|---------------------------------|---------------------------------|
| Identidade / profissão          | Localização temporária          |
| Características permanentes     | Estados temporários / emoções   |
| Origem / material               | Resultado de uma ação (particípio)|
| Hora / data                     | Progressivo (estar + gerúndio)  |

**Exemplos:**
- *Soy brasileño* × *Estoy en Madrid*
- *Es inteligente* × *Está cansado*
- *La mesa es de madera* × *La puerta está abierta*

### Haber (impessoal)
- Presente: **hay** (há / existe)
- Pretérito: **hubo**
- Imperfeito: **había**
- Futuro: **habrá**

### Irregulares frequentes no Presente
| Verbo   | yo      | tú       | él/ella  | nosotros | ellos    |
|---------|---------|----------|----------|----------|----------|
| ser     | soy     | eres     | es       | somos    | son      |
| estar   | estoy   | estás    | está     | estamos  | están   |
| ir      | voy     | vas      | va       | vamos    | van      |
| tener   | tengo   | tienes   | tiene    | tenemos  | tienen   |
| hacer   | hago    | haces    | hace     | hacemos  | hacen    |
| poder   | puedo   | puedes   | puede    | podemos  | pueden   |
| querer  | quiero  | quieres  | quiere   | queremos | quieren  |
| venir   | vengo   | vienes   | viene    | venimos  | vienen   |
| decir   | digo    | dices    | dice     | decimos  | dicen    |
| saber   | sé      | sabes    | sabe     | sabemos  | saben    |
| dar     | doy     | das      | da       | damos    | dan      |
| ver     | veo     | ves      | ve       | vemos    | ven      |

## 7. Gerúndio e Particípio

### Gerúndio
- **-AR** → **-ando** (*hablando*)
- **-ER / -IR** → **-iendo** (*comiendo, viviendo*)
- Irregulares: *diciendo, pidiendo, durmiendo, leyendo, oyendo...*

**Uso:** *estar + gerúndio* = contínuo  
*Estoy estudiando* = Estou estudando

### Particípio
- **-AR** → **-ado** (*hablado*)
- **-ER / -IR** → **-ido** (*comido, vivido*)
- Irregulares: *hecho, dicho, escrito, visto, puesto, abierto, muerto...*

**Uso:** tempos compostos com *haber*  
*He comido* = Eu comi / tenho comido

## 8. Preposições Mais Usadas

| Preposição | Uso principal                          | Exemplo                     |
|------------|----------------------------------------|-----------------------------|
| **a**      | Direção, objeto indireto, tempo        | *Voy a Madrid* / *A las 3*  |
| **de**     | Possessão, origem, material            | *El libro de Juan*          |
| **en**     | Localização (dentro), meio de transporte | *Estoy en casa*           |
| **con**    | Companhia, instrumento                 | *Voy con mis amigos*        |
| **por**    | Causa, duração, troca, meio            | *Lo hice por ti*            |
| **para**   | Finalidade, destino, prazo             | *Es para ti* / *Para mañana*|
| **sin**    | Sem                                    | *Café sin azúcar*           |
| **sobre**  | Sobre (em cima / a respeito)           | *El libro está sobre la mesa*|

**Por × Para (resumo rápido):**
- **Por** → motivo, duração, troca, “por causa de”
- **Para** → finalidade, destinatário, prazo, opinião

## 9. Formação de Frases

### Ordem básica
**Sujeito + Verbo + Complementos**  
(mas o sujeito é frequentemente omitido)

### Negação
Coloca-se **no** antes do verbo:  
*No hablo español*  
*No lo sé*

### Perguntas
- Com tom de voz / ponto de interrogação invertido: **¿...?**
- Pronomes interrogativos: *qué, quién, dónde, cuándo, cómo, por qué, cuánto*

Exemplos:
- *¿Cómo te llamas?*
- *¿Dónde vives?*
- *¿Cuántos años tienes?*

### Comparações
- Superioridade: **más ... que** → *más alto que*
- Inferioridade: **menos ... que** → *menos caro que*
- Igualdade: **tan ... como** → *tan inteligente como*
- Quantidade: **tanto/a(s) ... como**

## 10. Tempos Compostos (com Haber)

| Tempo                  | Forma                          | Exemplo                  |
|------------------------|--------------------------------|--------------------------|
| Pretérito Perfecto     | he + particípio                | *He comido*              |
| Pretérito Pluscuamperfecto | había + particípio         | *Había comido*           |
| Futuro Perfecto        | habré + particípio             | *Habré comido*           |
| Condicional Perfecto   | habría + particípio            | *Habría comido*          |

---

## 11. Dicas Rápidas

1. **Ser** = essência / **Estar** = estado ou lugar.
2. Pronomes objeto vão **antes** do verbo conjugado (exceto infinitivo, gerúndio e imperativo afirmativo).
3. O sujeito quase nunca precisa ser escrito.
4. Em perguntas e exclamações use os sinais invertidos: **¿ ¡**
5. O acento tônico é muito importante — muda o significado (*papa* × *papá*).
6. **Gustar** e verbos semelhantes: *Me gusta el café* (não “yo gusto”).
7. “There is/are” = **hay** (não muda no plural).
