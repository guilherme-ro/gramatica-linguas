## 1. Artigos

### Artigos definidos
| Gênero / Número | Artigo | Exemplo |
|-----------------|--------|---------|
| Masculino singular | **le** | le livre (o livro) |
| Feminino singular | **la** | la maison (a casa) |
| Plural (ambos) | **les** | les livres / les maisons |
| Diante de vogal ou h mudo | **l'** | l'homme, l'amie |

### Artigos indefinidos
| Gênero / Número | Artigo | Exemplo |
|-----------------|--------|---------|
| Masculino singular | **un** | un chat |
| Feminino singular | **une** | une table |
| Plural | **des** | des chats / des tables |

### Artigos partitivos (quantidade indeterminada)
| Gênero | Artigo | Exemplo |
|--------|--------|---------|
| Masculino | **du** | du pain (pão) |
| Feminino | **de la** | de la confiture (geleia) |
| Diante de vogal | **de l'** | de l'eau (água) |
| Plural | **des** | des fruits |

> **Negação**: em frases negativas, os partitivos e indefinidos viram **de** / **d'**  
> Ex: *Je n'ai pas de pain.* / *Je n'ai pas d'amis.*

## 2. Gênero e Número dos Substantivos

### Formação do feminino
- Maioria: acrescenta **-e** → *ami → amie*, *étudiant → étudiante*
- Terminação em **-eur** → **-euse** ou **-rice** → *vendeur → vendeuse*, *acteur → actrice*
- Terminação em **-f** → **-ve** → *actif → active*
- Terminação em **-x** → **-se** → *heureux → heureuse*
- Irregulares: *homme → femme*, *frère → sœur*, *roi → reine*

### Formação do plural
- Maioria: acrescenta **-s** → *livre → livres*
- Terminação em **-eau, -au, -eu** → **-x** → *bateau → bateaux*, *jeu → jeux*
- Terminação em **-al** → **-aux** → *journal → journaux* (exceções: *bal → bals*)
- Terminação em **-s, -x, -z** → não muda → *prix, nez, autobus*

## 3. Adjetivos

### Concordância
Os adjetivos concordam em gênero e número com o substantivo.

### Formação do feminino
- Acrescenta **-e**: *grand → grande*
- **-eux → -euse**: *heureux → heureuse*
- **-f → -ve**: *actif → active*
- **-er → -ère**: *premier → première*
- Irregulares: *beau → belle*, *nouveau → nouvelle*, *vieux → vieille*, *blanc → blanche*

### Posição
- **Antes** do substantivo (BAGS: Beauty, Age, Goodness, Size):  
  *une belle maison, un petit chat, un bon livre*
- **Depois** do substantivo (maioria):  
  *une voiture rouge, un homme intelligent*

### Comparativo e Superlativo
| Tipo | Estrutura | Exemplo |
|------|-----------|---------|
| Comparativo de superioridade | plus + adj + que | plus grand que |
| Comparativo de inferioridade | moins + adj + que | moins grand que |
| Comparativo de igualdade | aussi + adj + que | aussi grand que |
| Superlativo | le/la/les + plus/moins + adj | le plus grand |

Irregulares importantes:
- **bon** → meilleur / le meilleur
- **mauvais** → pire / le pire
- **petit** → moindre (sentido abstrato) / plus petit

## 4. Pronomes

### Pronomes pessoais sujeitos
| Pessoa | Pronome |
|--------|---------|
| 1ª sing. | je (j') |
| 2ª sing. | tu |
| 3ª sing. | il / elle / on |
| 1ª plur. | nous |
| 2ª plur. | vous |
| 3ª plur. | ils / elles |

### Pronomes objeto direto (COD)
**me / te / le / la / nous / vous / les**  
Ex: *Je le vois.* (Eu o vejo)

### Pronomes objeto indireto (COI)
**me / te / lui / nous / vous / leur**  
Ex: *Je lui parle.* (Eu falo com ele/ela)

### Pronomes tônicos (após preposição)
**moi, toi, lui, elle, nous, vous, eux, elles**  
Ex: *avec moi, pour elle, chez eux*

### Pronomes relativos
| Pronome | Uso | Exemplo |
|---------|-----|---------|
| **qui** | sujeito | L'homme qui parle |
| **que** | objeto direto | Le livre que je lis |
| **où** | lugar / tempo | La ville où j'habite |
| **dont** | de + complemento | Le livre dont je parle |
| **lequel / laquelle...** | após preposição | La table sur laquelle... |

### Pronomes demonstrativos
- **ce / cet / cette / ces** (adjetivos)
- **celui / celle / ceux / celles** (pronomes)
- **ceci / cela / ça**

### Pronomes possessivos
| Pessoa | Masculino | Feminino | Plural |
|--------|-----------|----------|--------|
| meu/minha | le mien | la mienne | les miens/miennes |
| teu/tua | le tien | la tienne | les tiens/tiennes |
| seu/sua | le sien | la sienne | les siens/siennes |
| nosso | le nôtre | la nôtre | les nôtres |
| vosso | le vôtre | la vôtre | les vôtres |
| deles | le leur | la leur | les leurs |

## 5. Verbos – Conjugações Essenciais

### Présent de l'indicatif

#### 1º grupo (-er) – parler
| Pessoa | Conjugação |
|--------|------------|
| je | parl**e** |
| tu | parl**es** |
| il/elle | parl**e** |
| nous | parl**ons** |
| vous | parl**ez** |
| ils/elles | parl**ent** |

#### 2º grupo (-ir) – finir
| Pessoa | Conjugação |
|--------|------------|
| je | fin**is** |
| tu | fin**is** |
| il/elle | fin**it** |
| nous | fin**issons** |
| vous | fin**issez** |
| ils/elles | fin**issent** |

#### 3º grupo (irregulares comuns)

**être** (ser/estar)
| je suis | nous sommes |
| tu es | vous êtes |
| il est | ils sont |

**avoir** (ter)
| j'ai | nous avons |
| tu as | vous avez |
| il a | ils ont |

**aller** (ir)
| je vais | nous allons |
| tu vas | vous allez |
| il va | ils vont |

**faire** (fazer)
| je fais | nous faisons |
| tu fais | vous faites |
| il fait | ils font |

**pouvoir** (poder)
| je peux | nous pouvons |
| tu peux | vous pouvez |
| il peut | ils peuvent |

**vouloir** (querer)
| je veux | nous voulons |
| tu veux | vous voulez |
| il veut | ils veulent |

**devoir** (dever)
| je dois | nous devons |
| tu dois | vous devez |
| il doit | ils doivent |

**savoir** (saber)
| je sais | nous savons |
| tu sais | vous savez |
| il sait | ils savent |

**venir** (vir)
| je viens | nous venons |
| tu viens | vous venez |
| il vient | ils viennent |

**prendre** (pegar/tomar)
| je prends | nous prenons |
| tu prends | vous prenez |
| il prend | ils prennent |

### Passé composé

**Formação**: auxiliar (**avoir** ou **être**) + particípio passado

#### Particípios passados comuns
| Infinitivo | Particípio |
|------------|------------|
| parler | parlé |
| finir | fini |
| être | été |
| avoir | eu |
| faire | fait |
| aller | allé |
| venir | venu |
| prendre | pris |
| voir | vu |
| écrire | écrit |
| dire | dit |
| mettre | mis |
| ouvrir | ouvert |

#### Verbos que usam **être** (Dr & Mrs Vandertramp + reflexivos)
- Devenir, Revenir, Monter, Rester, Sortir
- Venir, Aller, Naître, Descendre, Entrer, Rentrer
- Tomber, Retourner, Arriver, Mourir, Partir
- + todos os pronominais (se laver, s'appeler...)

> Com **être**, o particípio concorda em gênero e número com o sujeito:  
> *Elle est allée.* / *Ils sont partis.* / *Nous sommes arrivés.*

#### Negação no passé composé
**ne + auxiliar + pas + particípio**  
Ex: *Je n'ai pas parlé.* / *Elle n'est pas venue.*

---

### Imparfait

**Formação**: radical do *nous* do présent + terminações **-ais, -ais, -ait, -ions, -iez, -aient**

| parler → nous parlons | je parlais |
| finir → nous finissons | je finissais |
| être (irregular) | j'étais, tu étais, il était, nous étions... |

Uso principal: descrições, hábitos no passado, ações em progresso.

---

### Futur simple

**Formação**: infinitivo + terminações **-ai, -as, -a, -ons, -ez, -ont**

| je parlerai | nous parlerons |
| tu parleras | vous parlerez |
| il parlera | ils parleront |

Irregulares importantes:
- être → **ser**ai
- avoir → **aur**ai
- aller → **ir**ai
- faire → **fer**ai
- venir → **viendr**ai
- pouvoir → **pourr**ai
- vouloir → **voudr**ai
- devoir → **devr**ai
- savoir → **saur**ai
- voir → **verr**ai

---

### Conditionnel présent

Mesma base do futuro + terminações do imparfait: **-ais, -ais, -ait, -ions, -iez, -aient**

Ex: *je parlerais, tu finirais, il serait, nous aurions*

---

### Impératif (modo imperativo)

| | 2ª sing. | 1ª plur. | 2ª plur. |
|--|----------|----------|----------|
| parler | parle | parlons | parlez |
| finir | finis | finissons | finissez |
| aller | va | allons | allez |
| être | sois | soyons | soyez |
| avoir | aie | ayons | ayez |

> Com pronomes: *Regarde-moi !* / *Ne me regarde pas !*

## 6. Negação

Estrutura básica: **ne + verbo + pas**

Outras negações:
| Expressão | Significado |
|-----------|-------------|
| ne... jamais | nunca |
| ne... rien | nada |
| ne... personne | ninguém |
| ne... plus | não mais |
| ne... que | só / apenas |
| ne... nulle part | em nenhum lugar |
| ni... ni... | nem... nem... |

Ex: *Je ne mange jamais de viande.* / *Il n'y a personne.*

## 7. Perguntas

### 3 formas principais
1. **Entonação**: *Tu viens ?*
2. **Est-ce que**: *Est-ce que tu viens ?*
3. **Inversão**: *Viens-tu ?*

## 8. Preposições essenciais

| Preposição | Uso principal | Exemplo |
|------------|---------------|---------|
| **à** | lugar, tempo, COI | à Paris, à 8h, parler à |
| **de** | origem, posse, matéria | de France, le livre de, fait de |
| **en** | transporte, material, países femininos | en voiture, en bois, en France |
| **dans** | dentro de | dans la maison |
| **sur** | em cima de | sur la table |
| **sous** | embaixo de | sous le lit |
| **avec** | com | avec mon ami |
| **sans** | sem | sans sucre |
| **pour** | para / por | pour toi |
| **par** | por (agente) | par le professeur |
| **chez** | na casa de | chez Marie |
| **entre** | entre | entre nous |

### Contrações
- **à + le = au** → *au cinéma*
- **à + les = aux** → *aux États-Unis*
- **de + le = du** → *du pain*
- **de + les = des** → *des enfants*

---

## 9. Expressões com “y” e “en”

- **y** → substitui lugar introduzido por *à / dans / sur...*  
  Ex: *Tu vas à Paris ? → Oui, j'y vais.*

- **en** → substitui quantidade ou coisa introduzida por *de*  
  Ex: *Tu as des frères ? → Oui, j'en ai deux.*

## 12. Dicas rápidas de uso

- **Il y a** = há / existe → *Il y a un livre sur la table.*
- **C'est** vs **Il est**:  
  - *C'est un professeur.* (identificação)  
  - *Il est professeur.* (profissão, nacionalidade, religião)
- Hora: *Il est 8 heures.* / *Il est 8 heures et demie.* / *Il est 8 heures moins le quart.*
- Data: *Nous sommes le 13 octobre.* / *C'est aujourd'hui le 13.*
- Clima: *Il fait beau / chaud / froid / du vent / du soleil.*

---

## 13. Ordem dos pronomes (quando há vários)

**me/te/se/nous/vous** → **le/la/les** → **lui/leur** → **y** → **en**

Ex: *Il me le donne.* / *Je le lui donne.* / *Donne-le-moi !*
